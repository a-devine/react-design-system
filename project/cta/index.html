Usage notes

1 · Two ways to embed

Iframe (recommended) — isolated styles, won't conflict with the host page. Use ?embed=1 for transparent background. Code blocks above auto-resize the iframe to its content.

Copy-paste HTML — every file's <style>, <section>, and <script> blocks are scoped under one class (.cta-split, etc.) so they're safe to drop into a host page directly. You'll need to keep the Google Fonts link and the anime.js script too.

2 · Brand tokens

All four define the same scoped CSS variables: --ink, --paper, --paper2, --card, --line, --blue, --blue50, --blue100, --mute, --mute2. Override on the root section to retheme.

3 · Reduced motion

Every entrance respects prefers-reduced-motion. Users with the OS setting on see the final state instantly, no movement.

4 · Form submission

Each form fires two events when validated and submitted:

  • cta:submit CustomEvent on window, with { variant, context, data } in event.detail
  • postMessage to the parent window (for iframe embeds) with the same payload

The form prevents default and shows a success state. To wire to a real endpoint (HubSpot, Formspree, your API), add a listener that fetches the data.

5 · Analytics hooks

Every CTA root carries data-cta="vN-name" and data-cta-context="...". Listen for cta:submit and forward to your analytics:

window.addEventListener('cta:submit', e => analytics.track('audit_request', e.detail));

6 · Assets & dependencies

Each file expects ../assets/wordmark.svg and ../assets/favicon.svg from a shared assets folder. Loads Geist + Instrument Serif from Google Fonts, and anime.js v3.2.1 from jsDelivr. All cached aggressively.
